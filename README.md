# 안녕하세요, 주니어 AI 엔지니어입니다

안녕하세요. 구직 중인 주니어 AI 엔지니어입니다. Python과 머신러닝·딥러닝을 공부하며 데이터에서 의미 있는 인사이트를 찾고 실제 문제를 해결하는 AI를 만들고자 합니다. 프로젝트를 통해 데이터 전처리부터 모델 학습과 평가까지 경험하고, 결과와 배운 점을 기록하고 있습니다. 새로운 기술을 꾸준히 익히고 피드백을 열린 마음으로 반영하며 성장하겠습니다. 협업과 소통을 바탕으로 사용자에게 도움이 되는 서비스를 만드는 엔지니어가 되겠습니다. 함께 성장해요.
